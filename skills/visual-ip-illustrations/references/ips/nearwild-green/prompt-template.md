# Nearwild Green IP Prompt Template

## Planning fields

- Topic: `{Nearwild product idea}`
- Structure: `{discovery / handoff / trust checkpoint / optional help / reuse}`
- Nearwild Green action: `{one active verb}`
- Supporting objects: `{map, brief card, route marker, satchel, evidence folder}`
- Visible labels: `{short labels in the target language, if needed}`
- Output: `16:9` for article scenes or transparent full-body cutout for deck assets

## Single-image prompt

```text
Create an original editorial illustration for Nearwild about {topic}. Use the Nearwild Green IP: a moss-green fox-like local explorer with a warm cream face and tail tip, rust-red scarf, paper map, and canvas satchel. The character must perform one clear action: {action}. Use a warm paper texture, deep moss green, warm cream, rust red, and muted blue. Keep the composition calm, legible, and human. Preserve the full character silhouette and signature props. Leave generous empty space for any short {language} labels. No logos, no invented text, no real-person likeness, no travel-agency uniform, no photorealistic animal, no plastic 3D rendering, no copied composition.
```

## Deck cutout prompt

```text
Create a transparent full-body character cutout of the original Nearwild Green IP, a moss-green fox-like local explorer wearing a rust-red scarf, carrying a paper map and canvas satchel. Friendly curious expression, hand-drawn editorial illustration, warm cream highlights, clean silhouette, subtle paper texture, no words, no logo, no background, no extra characters.
```
