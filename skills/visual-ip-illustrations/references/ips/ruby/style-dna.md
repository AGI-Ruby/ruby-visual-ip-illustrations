## Core Style

Ruby images are clean hand-drawn/anime-line personal-IP illustrations. The image should feel like a lively human operator inside a product-thought sketch or a polished but still hand-drawn social illustration.

Ruby can be used in two output modes:

- `Ruby Article Sketch`: clean white or near-white article-body illustration, sparse supporting objects, Ruby performs a cognitive action, handwritten labels if needed.
- `Ruby Social IP`: avatar, sticker, half-body, wardrobe, or social visual asset with stronger character focus and minimal or no labels.

## Must Have

- Orange bob hair and black cat-eye glasses remain unmistakable.
- White or light inner top remains visible unless an explicitly requested outfit makes that impossible.
- Orange hand-drawn connection line/cable appears in article, sticker, wardrobe, or action images unless the user asks for a plain avatar.
- Black linework stays hand-drawn and expressive, not glossy vector-perfect.
- Ruby is active: holding, connecting, mapping, pointing, carrying, tuning, untangling, playing, gesturing, moving, or presenting.
- Background is clean white or near-white by default; transparent stickers use a removable chroma key source before alpha output.
- Text is sparse. For Chinese outputs, labels are Chinese unless the user requests English.

## Color

- Orange: hair and connection line. This is the route's signature color.
- Black: cat-eye glasses, linework, selected clothing, and readable outlines.
- White/off-white: inner top, page space, clean background, and breathing room.
- Red: lips, smile accent, small emphasis only.
- Navy/cream/black may appear as wardrobe colors.

Do not let background or clothing colors compete with orange hair and the orange connection line.

## Composition

- Article illustrations: 16:9 horizontal by default, Ruby performs one conceptual action, main subject around 35%-60% of canvas, with generous white space.
- Avatars: square, head-and-shoulders or upper bust, face unobstructed, glasses readable, outfit cues visible at neckline/shoulder.
- Transparent stickers: complete full-body or half-body character, centered with generous padding, clean alpha edges, no shadow unless requested.
- Wardrobe sheets: preserve stable identity while changing outfit language.
- Action stickers: one readable action per image, no explanatory text unless user asks for sticker captions.

## Visual Vetoes

Regenerate or edit when the result contains:

- generic anime-girl drift
- missing orange hair
- missing black cat-eye glasses
- wrong glasses shape
- missing hand-drawn orange connection line in non-plain-avatar outputs
- changed face identity
- passive decoration where Ruby can be removed without changing the image meaning
- over-glam fashion poster
- realistic photo drift
- chibi drift
- excessive text
- route leakage from Xiaohei, Littlebox, Tom, Ferris, or Seal
- copied composition from a prior accepted case unless the user asked for a derivative
- heavy gradients, dark backgrounds, dense UI screenshots, formal PPT diagrams, or corporate stock style
- labels covering Ruby's face, glasses, hair, hands, main prop, or orange connection line

## Stable Gates

- Ruby identity gate: orange bob hair, black cat-eye glasses, warm human face, red lips/smile, and hand-drawn linework are present.
- Ruby connection gate: orange hand-drawn connection line/cable appears when the output is article, sticker, wardrobe, or action based.
- Ruby action gate: Ruby performs the central expressive or cognitive action; removing Ruby breaks the image.
- Ruby wardrobe gate: outfit changes preserve the stable identity markers.
- Ruby route isolation gate: Ruby rules stay separate from Xiaohei, Littlebox, Tom, Ferris, Seal, and root legacy route identities.
