# Tomato Mascot Identity

- Route id: `tomato`
- Route status: `active`
- Output path: `assets/<article-slug>-tomato/`

## Stable markers

1. Round ripe red tomato body with hand-drawn texture.
2. Green leafy calyx on top, slightly irregular and lively.
3. Two simple dark eyes and a tiny friendly mouth; expression stays readable at small size.
4. Minimal orange-red line arms and legs; limbs support the action and never become a realistic anatomy study.
5. Warm, patient, curious personality: the mascot organizes a creator's work and helps people meet, but it does not speak for them.

## Action library

sort scattered notes, hold a photo, write in a notebook, compare versions, connect two tables with a bridge, carry a brief, inspect a checklist, approve a draft, grow a small content garden, guide an arrow, roll a task forward, and return to the next loop.

## Failure modes

logo-only still life, tomato body without calyx, red generic ball, fruit-human hybrid, black Xiaohei drift, human Ruby drift, over-cute chibi, realistic personification, copied composition, blocked action, and text-heavy poster treatment.
