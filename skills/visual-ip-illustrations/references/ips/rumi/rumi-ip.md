# Rumi IP

Rumi is the user's own long-haired golden shaded kitten, treated as a warm personal pet-account character.

## Recognition Rules

Keep these markers together:

- pale golden long hair
- round face
- large dark eyes
- white fluffy chest ruff
- long ear furnishings
- natural kitten proportions
- optional toast-shaped collar tag

## Action Responsibility

Rumi should perform the central action in each image: inspect a brush, peek from a cat bed, track a toy, sit beside a growth chart, pose for a portrait, react to a new object, or invite the viewer into a gentle pet story.

The image should lose its meaning if Rumi is removed. Use the character as the subject, not a decorative sticker placed in a corner.
